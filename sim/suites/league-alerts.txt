# 살아 있고, BDR 신청 사이트에 안 알린 새 D7 대회가 하나 있다. 태블릿처럼 스크립트를 한 번만 로드한다.
#
#   1. 개인톡(1:1)에서 친다 — 투표 연결과 달리 개인톡도 된다
#   2. 인자 없음·형식·틀린 코드 → 거부
#   3. 맞는 코드 → 답장이 안내 + 지금 신청 가능 2건(D-5 · 2/6팀, D-30). 바로 뒤에 메시지함에서
#      "[BDR 신청] 새 대회 접수가 열렸습니다"가 **이 개인톡으로** 나간다
#   4. 같은 코드를 단톡방에서 다시 → 거부(한 번 쓰면 끝)
#   5. `!대회` — 단톡방에서 누구나. 신청 가능 2건 + BDR 최근 공지 1건. 필터 밖 D6·관심 없음·마감 지남·
#      20일 전 BDR 글은 안 나온다
#   6. `!대회 용인` → 용인 D5만, `!대회 없는말` → 없다는 답
#
# 다음 확인 간격(`@tick`)은 보지 않는다 — 앞 시나리오가 남긴 열린 투표에 따라 1분/30분이 갈린다.
