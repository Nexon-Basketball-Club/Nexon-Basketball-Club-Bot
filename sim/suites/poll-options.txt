# 선택지가 둘인 투표(1부 정원 2 / 2부 무제한). 시나리오가 "원동현"을 미신청으로 둔다.
#
#   1. 도움말이 선택지 이름을 띄운다
#   2. `!참석`만 치면 거절 + 칠 줄(`!참석 1부` / `!참석 2부`)
#   3. `!참석 원동현`(조회 습관)은 선택지가 여럿일 때만 거절된다 — 하나면 무시된다(poll 스위트)
#   4. `!참석 1부` → 1부 대기 2번. 다른 선택지로 또 치면 중복으로 원래 자리를 알려준다
#   5. 현황은 선택지별로 나뉜다. 무제한인 2부엔 대기가 없다
#   6. 취소 후 `!참석 2 부`(띄어 씀)도 2부로 들어간다
!도움말
!참석
!참석 원동현
!참석 1부
!참석 2부
!투표현황
!내순번
!취소
!참석 2 부
!취소
