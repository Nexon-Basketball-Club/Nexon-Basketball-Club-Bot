# sender("원동현")를 확정 4번에 넣어두므로, 아래 다섯 줄이 한 줄기로 전 분기를 지난다:
#
#   1. 이미 확정된 사람이 또 신청  → 중복 (순번이 안 바뀐다)
#   2. 확정자가 취소             → **승계가 같은 답장에 실린다** (이 기능의 핵심)
#   3. 다시 신청                 → 줄 맨 뒤 (자리를 놓았으면 뒤로)
#   4. 대기자가 취소             → 승계 줄이 없다
#   5. 신청 없는 사람이 취소      → NOT_VOTED 분기
#
# 2번 줄이 사라지면 대기자는 자기 차례가 온 걸 영영 모른다 — 봇은 먼저 말을 걸 수 없다.
